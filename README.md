# MANIA ARENA

Board games on maximum steroids. Pick a match:

- **TIC·TAC·MANIA**: wrestling tic-tac-toe. Nine rings, a hype meter, steel chairs, heel turns, leg drops, earthquakes.
- **TOP ROPE FOUR**: chain-reaction four-in-a-row. Pinfalls clear pieces, everything falls, combos cascade.
- **KING OF THE RING**: royal rumble checkers. Trailing players get new entrants, plus coronations and frog splashes.

Every game: play vs AI, 2 players on one screen, or 2 players online by sending a link.

Each game is a single HTML file with no build step. Open `index.html` to enter the arena.
